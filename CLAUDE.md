# Project rules

## Git

- **Work on `master` directly.** Never create a branch for a change and never
  ask whether to — commit straight to `master`, even though it is the default
  branch. This overrides any default "branch first" behaviour.
- **Always commit after making changes.** When a piece of work is finished and
  verified, stage it and commit it without being asked. Don't leave finished
  work sitting in the working tree.
